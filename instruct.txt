Application Purpose

Develop a web application to generate a transport schedule for barges transporting monopiles from a fabrication yard to a marshalling port.

The application structure, navigation and layout shall follow the existing repository:

https://github.com/MLUY/tidal_transport

Input Tab
Application Header
Title

Tidal Transport Planner

Description

Short description:

This application generates transport schedules for monopile transport barges while considering cargo weight classes, barge configurations and tidal restrictions.

Barge Data

The user shall be able to define a fleet of barges.

Each barge shall have:

Field	Type
Name	Text
Configuration	Single / Double

Default barges:

Name	Configuration
barge_1	Double
barge_2	Double
barge_3	Single

Rules:
Single Configuration
Can carry exactly 1 monopile.
Cannot carry 2 monopiles.
Double Configuration
Can carry:
1 monopile
2 monopile

Cargo Weight Classes
User shall define cargo classes.
Default values:

Class	From Weight (t)	To Weight (t)
A	1000	1200
B	1200	1400
C	1400	1600
D	1600	1800

The number of classes shall be editable.

barge cycle
user shall define a barge cycle per barge

activity hr
loading per monopile 24hr
sailing 96hr
discharging 2hr

discharging can only take place when tide is higher than indicated in the barge table
if discharging cannot take place barge needs to wait until tide reaches the level

Tide Restrictions Matrix

Based on the barges defined above, the application shall automatically generate a tide restriction table.

The matrix defines the minimum required tide level (cm) for each operating condition.

Single Monopile Transport

For every barge, one row shall be generated representing:
Single monopile transport.
Minimum required tide level per cargo class.

Default:

Name	Configuration	A	B	C	D
barge_1	Single	600	620	640	660
barge_2	Single	600	620	640	660
barge_3	Single	600	620	640	x
Double Monopile Transport

Only available for barges with configuration = Double.

One additional row shall be generated.

Rules:

Tide requirement is determined by the heaviest monopile on board.
Class shown represents the highest class carried.
"x" indicates that cargo combination is not permitted.

Default:

Name	Configuration	A	B	C	D
barge_1	Double	650	700	x	x
barge_2	Double	650	700	x	x
